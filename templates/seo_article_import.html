批次匯入舊文章

把官網既有文章標題貼進來，系統會自動寫入 seo_articles，讓 AI 生成新文章時不會重複主題。
支援「一行一標題」或「標題 | URL」格式（URL 這次略過，僅記標題）。

{% if result %}
{{ result.inserted }}
新增
{{ result.updated }}
更新
{{ result.skipped }}
略過
{{ result.failed }}
失敗
{% if result.errors %}
失敗原因：
    {% for e in result.errors %}
  • {{ e }}
    • {% endfor %}
{% endif %}
{% endif %}
格式 A：一行一標題
格式 B：標題 | URL（URL 本次略過，僅記標題）
空白行、少於 4 字的標題、欄位名稱列（「標題」「文章」「部落格」）會自動略過。
